# AWS SAA-C03 Notes

Personal study notes for the AWS Certified Solutions Architect – Associate (SAA-C03) certification, based on the course by **Manara**.

## Your Guide to the Exam

- **Format:** 65 questions
- **Delivery method:** Pearson VUE testing center or online proctored exam
- **Duration:** 130 minutes

## Exam Structure & Content

The AWS Certified Solutions Architect - Associate (SAA-C03) exam is designed for individuals in a solutions architect role. It assesses a candidate's ability to design solutions following the AWS Well-Architected Framework.

There are two types of questions on the exam:

- **Multiple choice:** Has one correct response and three incorrect responses (distractors)
- **Multiple response:** Has two or more correct responses out of five or more response options

The exam has the following content domains and weightings:

| Domain | Weighting |
|---|---|
| Domain 1: Design Secure Architectures | 30% |
| Domain 2: Design Resilient Architectures | 26% |
| Domain 3: Design High-Performing Architectures | 24% |
| Domain 4: Design Cost-Optimized Architectures | 20% |
